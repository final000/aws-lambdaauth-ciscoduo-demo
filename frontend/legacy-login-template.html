Demo 6: Username/Password + JWT

Traditional login against a legacy auth API. App issues its own JWT, Lambda authorizer validates it.

Step 1: Login

Credentials are sent to POST /legacy/login. On success, the server verifies against the legacy auth API and returns a signed JWT. Token is stored in memory only (not localStorage).
